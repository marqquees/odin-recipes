# odin-recipes

This project is the first [exercise](https://www.theodinproject.com/lessons/foundations-recipes) in the syllabus for the **Foundations** course of **The Odin Project**.

The aim of this project is to create three **HTML** files, comprising three recipes of the student’s choice. The recipes consist of semantic tags, such as: links, titles, ordered and unordered lists, paragraphs and images.

There is also an additional research task to be carried out, which involves gathering recipe content and free images available on the web.

**Skills**:
- conducting research;
- creating a semantic structure that respects the hierarchy;
- navigation;
- displaying images.
